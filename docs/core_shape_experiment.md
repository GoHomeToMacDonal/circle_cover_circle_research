# 圆心附近同形微缩图形实验

## 构造

对每个 owner 圆心 `c_i`，外层点写成

```text
p = c_i + rho*u.
```

加入同心、同方向的微缩副本

```text
p_core = c_i + epsilon*rho*u = c_i + epsilon*(p-c_i),
0 < epsilon < 1.
```

所以 core 图形逐点保持外边界的方向和组合形状，半径为 `epsilon*rho`。`epsilon=0` 在代码中约定为“不加入 core”的基线，而不是把所有副本退化为重复圆心点。

该构造有三个直接性质：

1. 每个 core 点到 owner 圆心的距离严格为 `epsilon*rho`；
2. core 点是圆心和外点的凸组合，因此只要外点在目标盘内，core 点也在目标盘内；
3. 外点仍保留，所以每组局部最小包围圆半径仍为 `rho`。

实现为 `src/private_region_family.py` 的 `boundary_with_core_family()`。外层 level 0/1/2/3 加 core 后分别有 256/608/1184/2336 点。

## 计算设置

`src/core_shape_experiment.py` 对 `rho`、外层 level、`epsilon` 和覆盖半径因子进行扫描。每个 case 独立设置 wall-clock、候选数和 DFS 节点硬预算，持续输出 JSON 进度并增量保存紧凑结果。以下实验均使用严格小于目标的覆盖半径

```text
r = 0.99*rho.
```

因此，只要找到至多 25 圆的 witness，就已经说明该有限点集不能满足 `tau_25=rho`。表中的 `unknown` 区间是预算内的组合上下界，不表示精确最优值。

## 仅使用原始外层顶点（outer level 0）

取 `rho=0.99`：

| epsilon | 总点数 | 候选圆 | 极大 mask | 覆盖数结果 | 状态 |
|---:|---:|---:|---:|---:|---|
| 0（无 core） | 128 | 3,216 | 104 | **16** | 浮点超图最优 |
| 0.02 | 256 | 13,032 | 192 | **17** | 浮点超图最优 |
| 0.05 | 256 | 13,032 | 384 | **17** | 浮点超图最优 |
| 0.10 | 256 | 12,648 | 608 | **17** | 浮点超图最优 |
| 0.20 | 256 | 12,456 | 712 | 13–19 | 15 秒超时 |
| 0.30 | 256 | 11,896 | 632 | 14–21 | 15 秒超时 |

真正很小的 core（2%–10%）把覆盖数从 16 提高到 17，但只增加了一个圆，远未接近 25。较大的 core 能提高当前找到的上界，但仍存在 19 或 21 圆的严格小半径覆盖。

## 与一级外边界加密叠加

`rho=0.99`、outer level 1，共 304 外点；加入 core 后共 608 点：

| epsilon | 覆盖数界 | 已找到的严格小半径圆数 |
|---:|---:|---:|
| 0（上一轮无 core） | 14–18 | 18 |
| 0.05 | 14–19 | 19 |
| 0.20 | 16–21 | 21 |
| 0.30 | 16–23 | 23 |
| 0.40 | 16–21 | 21 |
| 0.50 | 16–23 | 23 |

效果并不随 `epsilon` 单调：0.4 比 0.3、0.5 更容易重组。这表明变化由候选覆盖超图的组合事件控制，并非简单地“core 越大越强”。

## 更密外层和趋近 rho=1

| rho | outer level | epsilon | 总点数 | 覆盖数界 | 严格小半径 witness |
|---:|---:|---:|---:|---:|---:|
| 0.99 | 2 | 0.05 | 1,184 | 16–22 | 22 圆 |
| 0.999999 | 1 | 0.05 | 608 | 14–19 | 19 圆 |

作为比较，无 core 的 outer level 2 已有 21 圆覆盖；加入 5% core 后只提高到 22。把 `rho` 推到 `0.999999` 后，5% core 仍可由 19 个半径 `0.98999901` 的圆覆盖。所有保存的 witness 均重新由圆心重放；未覆盖点数为 0，且实际半径与 `rho` 之间保留约 0.01 的显著裕量。

## 为什么没有形成 must-link

对三个代表性的 `epsilon=0.05` witness 检查每个竞争圆实际覆盖的 owner 和层：

| rho / level | 圆数 | 多 owner 圆数 | 同时覆盖 outer+core 的圆数 | 单圆最多 owner 数 |
|---|---:|---:|---:|---:|
| 0.99 / 0 | 17 | 17 | 17 | 6 |
| 0.99 / 2 | 22 | 22 | 22 | 6 |
| 0.999999 / 1 | 19 | 19 | 19 | 6 |

每一个竞争圆都同时混合多个 owner，并同时服务外点与 core 点。也就是说，小图形没有把自己的外层形状“绑定”到同一个覆盖圆；相反，因为覆盖半径约为 `rho`，远大于 `epsilon*rho`，一个竞争圆很容易吞入多个邻近 owner 的 core 点，再与其他 owner 的外点重新配对。

## 结论

圆心同形微缩图形确实让重组略微变难，但单一小 core 不是有效的 must-link gadget：

- 2%–10% core 在最清楚的 level 0 实验中只把最优值从 16 提高到 17；
- 与外边界加密叠加后通常只多需要约一个圆；
- 甚至 1,184 点、5% core 的实例仍有 22 圆严格小半径覆盖；
- 跨组关联没有消失，所有 witness 圆仍混合 2–6 个 owner。

如果继续沿此方向，更值得尝试的不是单个更大的同心副本，而是多个半径层或连接 outer/core 对应方向的径向“辐条”点列；这些结构才可能惩罚把同一方向的内外点分配给不同圆。不过它们仍必须通过无预定分组的全局集合覆盖验证。
